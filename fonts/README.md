# Fontes

Impact é a fonte de 94% das caixas do catálogo do 9GAG — é ela que dá o
visual de meme. Não é redistribuível, então não está versionada aqui.

Coloque `Impact.ttf` neste diretório e o renderizador a usa automaticamente.
Sem ela, cai para Liberation Sans Bold ou DejaVu Sans Bold, que existem na
maioria das distribuições Linux. O resultado fica legível, mas não idêntico
ao original.

No macOS e no Windows a Impact já vem instalada e é encontrada pelo caminho
do sistema, sem precisar copiar nada.
